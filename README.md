# 밤의 계보 — 갱스터 인생 시뮬레이션

브라우저에서 바로 하는 갱스터 인생 시뮬레이션 게임. 설치 없이 `index.html` 하나로 돌아간다.

## 하는 법
- 바로 하기: GitHub Pages 링크로 접속
- 직접 받기: `index.html`을 내려받아 브라우저로 열기

## 게임 내용
- 한국(부산·서울) · 일본(오사카·도쿄) · 중국(상하이·홍콩) · 미국(LA·뉴욕)
- 밑바닥 막내부터 시작해 두목 자리를 물려받거나, 내 조직을 창업
- 구역 습격(전술 선택), 동생 계급·오른팔·의형제, 숙적 간부, 밀수, 연애·결혼·계보 대물림
- 검찰 수사, 재판, 감옥, 배신, 은퇴, 밤의 왕 · 밤의 황제 엔딩

저장은 브라우저(localStorage)에 된다. 등장 조직과 인물은 모두 가상이다.
